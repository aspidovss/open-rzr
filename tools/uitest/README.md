# Window tests

The window (`ui/`) runs in a normal browser against `devmock.js`, a stand-in for the Rust side of
the app. No mouse and no Tauri are needed.

```
cd tools/uitest
npm install
npx playwright install chromium
npm test                 # build.js + i18n-check.js + smoke.js
node smoke.js --shots    # also screenshots of every page into shots/
```

* `build.js` writes `ui/test.html` (the real `index.html` with the mock in front of it) and
  `sigs.js` — the argument names of every `#[tauri::command]` in `app/src`. The mock refuses a call
  whose arguments do not match, the same way the real app would.
* `i18n-check.js` — every key the window uses exists in English and Russian, and both files have
  the same keys.
* `smoke.js` — every tab and page opens, the diagnostics dialogs work, "Undo", close to tray,
  the raw command; no JavaScript errors. It serves the repository on a local port (the help pages
  are fetched, which `file://` pages may not do).

To try the window by hand: `node build.js`, then open `ui/test.html?lang=en` through any local web
server (e.g. `python3 -m http.server` in the repository root → http://localhost:8000/ui/test.html).
Options: `lang=en|ru`, `db`, `ord` (OpenRazer driver present), `rz` (Razer Synapse running),
`os=windows|linux`, `style=synapse|classic`, `poly`.

When a command is added or changed in `app/src`, add its mock to `devmock.js` (look for the command
next to it) — `sigs.js` is regenerated by `build.js`.
