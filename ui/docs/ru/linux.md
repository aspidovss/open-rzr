# Linux

## Доступ к мыши (udev)

Без правила к мыши может обращаться только root. При первом запуске open-rzr предложит установить `/etc/udev/rules.d/99-open-rzr.rules` (один раз спросит пароль); то же делает `open-rzr-cli install-udev`, а пакет `.deb` ставит правило сам. Правило даёт пользователю сеанса доступ к:

- интерфейсу управления (`hidraw`) известных open-rzr мышей Razer — по кабелю, через приёмник и по Bluetooth;
- собственным событиям клавиш мыши (`/dev/input/event*`) — для клавиш-триггеров F13–F24 действий программы в макросах.

После установки правила переподключите мышь.

## OpenRazer

[OpenRazer](https://openrazer.github.io) — открытый драйвер (`razermouse`) и служба для устройств Razer в Linux. Две программы, обращающиеся к одной мыши, получают ответы друг друга, поэтому open-rzr умеет работать **через** драйвер OpenRazer: DPI, частота опроса, батарея, сон и подсветка идут через его файлы sysfs, и ядро упорядочивает их со службой. Кнопки, макросы, профили и боковая панель, которых нет в драйвере, по-прежнему идут напрямую.

**Настройки → Совместимость с OpenRazer:**

| Режим | Поведение |
|---|---|
| Автоматически (по умолчанию) | через драйвер OpenRazer, если он подключён к мыши, иначе напрямую |
| Всегда через OpenRazer | то же, с предупреждением в журнале, если драйвера нет |
| Выключено | всегда напрямую; остановите службу (`systemctl --user stop openrazer-daemon`) |

При запуске служба OpenRazer восстанавливает свою сохранённую подсветку и DPI.

## Polychromatic

[Polychromatic](https://github.com/polychromatic/polychromatic) (GPL-3.0) — программа управления подсветкой для OpenRazer. open-rzr работает **рядом** с ней и только запускает её как отдельную программу:

- если она установлена, в Настройках и меню трея появляется *Открыть Polychromatic*;
- пока она запущена, open-rzr работает через драйвер OpenRazer и оставляет подсветку ей (страница «Подсветка» заблокирована; *Всё равно управлять здесь* снимает блокировку);
- кнопки, макросы, профили в памяти и связь с программами остаются в open-rzr.

## Трей и автозапуск

open-rzr может запускаться вместе с системой (`~/.config/autostart`) и работать в трее. Закрытие окна оставляет её в трее; **Выход** в меню трея завершает работу.
