# Решение проблем

## Мышь не находится или не отвечает

1. С мышью работает **Razer Synapse или OpenRazer** — смотрите предупреждение сверху и остановите их ([Windows](windows.md), [Linux](linux.md)).
2. **Linux:** нет правила udev — *Настройки* предложат его установить; после этого переподключите мышь.
3. **Bluetooth:** по Bluetooth настройка может быть недоступна — подключите кабелем или через приёмник ([подробнее](devices.md)).
4. **Диагностика → Все HID-устройства** показывает, что видит система. **Диагностика → Драйверы** — драйверы Razer, оставшиеся от Synapse.
5. Нажмите **⟳** рядом со списком устройств.

## Кнопка делает не то

- Проверьте слой: **Обычный** или **Hypershift**.
- *Найти нажатием…* покажет, какую кнопку вы нажали.
- *По умолчанию* в окне назначения возвращает заводское назначение; *••• → Сбросить* — для всех кнопок.

## Изменения пропадают после отключения мыши

Профиль не записан в слот: кнопка рядом с ним показывает **● Записать в мышь** — нажмите её ([Профили](profiles.md)).

## Отправить отчёт

**Диагностика → Сохранить отчёт** собирает список HID-устройств, состояние мыши, все кнопки с байтами и последние 800 строк журнала. open-rzr ничего никуда не отправляет — приложите файл к сообщению или issue на GitHub.

## Где что лежит

| | Windows | Linux |
|---|---|---|
| Настройки | `%APPDATA%\open-rzr\settings.json` | `~/.config/open-rzr/settings.json` |
| Профили | `%APPDATA%\open-rzr\profiles\` | `~/.config/open-rzr/profiles/` |
| Журнал | `%APPDATA%\open-rzr\logs\open-rzr.log` | `~/.config/open-rzr/logs/open-rzr.log` |
| Резервные копии | `%APPDATA%\open-rzr\backups\` | `~/.config/open-rzr/backups/` |

Журнал ротируется при 2 МБ, хранятся пять старых файлов; время — UTC.
