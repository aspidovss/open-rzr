# Поддерживаемые мыши и Bluetooth

| Поддержка | Модели | Что работает |
|---|---|---|
| **Проверенный модуль** | Razer Naga Pro: кабель (`1532:008F`) и приёмник HyperSpeed (`1532:0090`) | всё |
| **Семейство Naga Pro**, не проверено | Naga V2 Pro (`00A7`, `00A8`); Naga Pro по Bluetooth (`0092`) | всё, экспериментально |
| **База OpenRazer + проверка памяти** | 68 современных мышей: Basilisk V2/V3, DeathAdder V2/V3, Viper Ultimate, Viper V2/V3, Cobra Pro, Naga X, Naga V2 HyperSpeed, Pro Click… | то, что подтверждает база, плюс кнопки, макросы и профили, если мышь на них отвечает (экспериментально) |
| **База OpenRazer** | более старые мыши | DPI, стадии, частота опроса, батарея, сон, подсветка — что подтверждает база |

Полный список: **Настройки → Поддерживаемые устройства** или `open-rzr-cli devices`.

## Проверка памяти

Современные мыши Razer используют те же команды кнопок, макросов и профилей, что и Naga Pro. При подключении open-rzr спрашивает такую мышь запросами **только на чтение** (назначение левой кнопки, число профилей, список макросов). То, на что она отвечает, включается с пометкой *экспериментально* и подсказкой сначала сделать резервную копию.

Кнопки находятся перебором. Одинаковые у всех мышей Razer (левая, правая, средняя, назад, вперёд, колесо) получают названия и заводские назначения; остальные показываются как *Кнопка 0x..* с тем, что они делают сейчас, и их можно переименовать. На рисунке — только кнопки, которые есть у мыши; у Naga без сменных панелей (Naga X, Left-Handed, V2 HyperSpeed) появляется вид сбоку с 12 клавишами.

## Bluetooth

По Bluetooth LE Naga Pro для системы — другое устройство (номер модели `0092`) с шестью HID-устройствами (мышь, клавиатура, медиа-клавиши, системные клавиши и ещё два). Все они только передают ввод: команды настройки, которые работают по кабелю, ни одно из них не принимает. Канал настроек Naga Pro по Bluetooth — отдельный GATT-сервис производителя (`52401523-…`), который open-rzr пока умеет только исследовать — см. ниже.

- Если одно из них отвечает на команды настройки, мышь настраивается так же, как по кабелю.
- Если нет, open-rzr так и пишет: для изменения настроек подключите мышь кабелем или через приёмник HyperSpeed. Настройки остаются в мыши и работают и по Bluetooth.

**Диагностика → Беспроводное** показывает для мыши на Bluetooth её HID-устройства с длинами и номерами отчётов, GATT-сервисы и характеристики (читаемые значения читаются — заряд, сведения об устройстве) и умеет делать **пробу** запросом «версия прошивки» (только чтение). Всё пишется и в журнал, так что попадает в *Сохранить отчёт*. **Диагностика → Все HID-устройства** показывает каждое устройство с назначением (★ — от производителя) и типом подключения — полезно, когда мышь не находится.

**GATT-канал Razer** (в том же окне, Windows): подписывается на уведомления характеристик сервиса производителя, записывает запрос в его записываемую характеристику — только слушать, запрос прошивки (только чтение) или введённые байты — и показывает каждое уведомление со временем. Это помощь в разборе протокола Bluetooth: слушайте, нажимая кнопки или меняя DPI, затем отправьте отчёт.

## Другая мышь

Если ваша мышь отмечена как *экспериментальная* и что-то работает неправильно, пришлите отчёт из **Диагностика → Сохранить отчёт**. Полноценный модуль новой модели (названия, рисунок, заводские назначения) начинается с копии `crates/rzr-devices/src/naga_pro.rs`.

## Файлы устройств

Модель, которой нет в списке (или у которой запись не совсем верна), можно описать файлом, без пересборки. Положите по одному `*.toml` (или `*.json`) на устройство в папку **devices**: **Диагностика → Файлы устройств** показывает папку, перечитывает её и выводит ошибки. В Windows это `%APPDATA%\open-rzr\devices`, в Linux — `~/.config/open-rzr/devices`.

Файл берёт за основу запись базы OpenRazer с тем же product id (или модель из `base_pid`, например `0x008F` для «родственника» Naga Pro) и меняет только то, что в нём указано:

```toml
pid = 0x00AB                    # product id (Диспетчер устройств / lsusb: 1532:00ab)
name = "Razer Example Mouse"
# base_pid = 0x008F             # основа — известная модель, а не запись OpenRazer
transaction_id = 0x1F
wireless = false
battery = false
max_dpi = 26000
dpi_stages = 5
features = ["firmware", "serial", "dpi", "dpi_stages", "polling", "lighting"]

[[zones]]
id = "logo"                     # scroll, logo, side, left, right, backlight
led = 0x04
effects = ["off", "static", "spectrum", "breath"]

[[buttons]]
id = 0x60
name = "DPI down"
```

Функции: firmware, serial, dpi, dpi_stages, polling, battery, charging, idle, low_battery, lighting, buttons, macros, profiles, side_plate. Эффекты: off, static, spectrum, wave, breath, reactive, custom. Неизвестные ключи и названия выводятся как предупреждения. Проверенный модуль (Naga Pro) не заменяется, если в файле нет `override = true`. Модели из файлов помечаются как *ваш файл* и считаются экспериментальными. В командной строке то же самое: `open-rzr-cli device-files`.
